`dspi_10mhz_loopbackDifficulty: IntermediateUses MCU: YesExternal Hardware: NoneOverviewThis example demonstrates a custom 10 MHz Dual-SPI (DSPI) implementation on the Shrike platform. By utilizing 2 data lines simultaneously, it doubles the throughput of standard SPI.The project uses the RP2040's Programmable I/O (PIO) to act as the DSPI master, generating the clock and bitbanging the dual data lines. On the FPGA side, it implements an oversampled target (slave) state machine that uses the ForgeFPGA's internal 50 MHz clock to detect SPI clock edges. It includes a loopback mechanism where data typed into the MCU serial console is transmitted via DSPI, captured by the FPGA, and echoed back, alongside periodic asynchronous heartbeat alerts generated by the FPGA.You will learn how to bypass standard SPI limitations using PIO, handle bidirectional data lines (inouts), and implement clock-domain edge detection on the ForgeFPGA.CompatibilityBoardFirmware StatusShrike-Lite (RP2040)firmware/micropython/ ✅ TestedShrike (RP2350)firmware/micropython/ ✅ TestedShrike-fi (ESP32-S3)firmware/micropython/` ⬜ `UntestedFPGA bitstream is the same across all boards.Hardware SetupNo external hardware required.
